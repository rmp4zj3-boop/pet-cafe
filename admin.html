☁️ 雲端即時同步設定

設定 Firebase 後，所有裝置開啟網頁即可自動同步菜單、訂單等資料。

未設定

📋 設定步驟（一次性，免費）：

  1. 前往 console.firebase.google.com 建立新專案
  2. 在專案中新增「Realtime Database」，地區選 asia-southeast1
  3. 資料庫安全規則選「以測試模式啟動」（或參考下方進階規則）
  4. 前往「專案設定 > 一般」→ 點選「新增應用程式」→ 選 Web (</>)
  5. 複製「firebaseConfig」物件內容，貼入下方輸入框
🔐 進階：推薦的資料庫安全規則 
{
  "rules": {
    "petcafe": {
      ".read": true,
      ".write": true
    }
  }
}

⚠️ 測試期間可用上述規則。正式營運後建議加入 IP 限制或身份驗證。
